# 고3 모의고사 준비 허브 설계

## 의도

바이브 코딩으로 만들 고3 모의고사 관련 프로그램들을 한곳에서 정리하고, 첫 도구를 바로 써볼 수 있는 개인용 허브를 만든다. 첫 도구는 모의고사 학습 정보를 기록·검색·복습하는 간단한 정보 정리 웹앱이다.

## 목표와 범위

- 허브에서 프로그램 이름, 설명, 상태, 링크를 카드로 관리한다.
- 첫 카드에서 모의고사 정보 정리 앱으로 이동한다.
- 정보 정리 앱에서 회차/날짜, 과목, 유형(개념·오답·질문·학습 메모), 제목, 내용, 복습일을 기록하고 검색·필터·삭제한다.
- 허브와 앱 데이터는 브라우저 `localStorage`에 저장한다. 서버와 로그인은 두지 않는다.
- 전체 시각 디자인은 사용자가 지정한 2027학년도 EBS 수능특강 교재 표지 이미지 자체를 활용한다. 과목 표지는 여러 종이므로 공식 교재 페이지의 문학 표지를 대표 이미지로 정하고, 출처로 연결한다.
- 반응형 화면과 키보드 조작, 읽을 수 있는 대비를 지원한다.
- 완성 후 Sites에 배포해 공개 HTTPS 주소를 확보하고, 그 주소로 ‘교사의 별자리’ 등록 안내 절차를 따른다.

## 제외 범위

- 계정, 서버 저장, 여러 기기 간 동기화
- 성적 분석이나 모의고사 문제 제공
- 첫 버전에서 별도 프로그램의 실행 화면까지 허브 안에 삽입하는 기능

## 접근 방식

1. **정적 단일 페이지 앱 (선택 제안):** HTML/CSS/JavaScript와 브라우저 저장소로 허브와 첫 도구를 구현한다. 빈 저장소에서 시작하기 쉽고 백엔드 없이 배포 주소를 만들 수 있다.
2. **프레임워크 기반 SPA:** 화면 전환과 재사용성은 좋아지지만, 현재 요구의 작은 범위에 의존성과 빌드 단계를 더한다.
3. **서버 기반 포털:** 공유와 동기화가 가능하지만 로그인·데이터베이스가 필요해 프론트엔드 전용 조건과 맞지 않는다.

## 구현자 결정

- 선택 제안은 1번이다.
- 허브 카드와 첫 앱을 한 사이트의 두 화면으로 구성한다.
- 첫 앱의 정보 레코드는 회차/날짜·과목·유형·제목·내용·복습일 필드를 가진다.
- 공식 EBS 교재 페이지에서 2027학년도 수능특강 문학의 표지 이미지를 사용한다. 각 교재 표지가 다르므로 대표 과목을 하나 정해야 하며, 문학을 임시 기본값으로 제안한다.
- 등록 API 지침상 주소는 실제 공개 HTTPS 배포 URL이어야 한다. 로컬 주소를 제출하지 않으며, 등록 JSON에는 허용된 공개 필드만 담는다.

## 확인이 필요한 점

- 이 설계와 정적 단일 페이지 구현 방향을 승인할지
- 수능특강의 특정 과목 표지를 원한다면 문학 대신 어느 과목인지
- 등록에 사용할 공개 허브 이름과 소개는 배포 결과를 보고 최종 확인한다. 실명·학교·연락처 같은 개인정보는 등록하지 않는다.
